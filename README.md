# Concierge 🛎️

Agente master: assistente pessoal que coordena a rotina, as tarefas e os outros agentes — de forma proativa, com foco no bem-estar.

## Como funciona
- **Cérebro**: [`CLAUDE.md`](CLAUDE.md) — a constituição (missão, níveis de autonomia, regras de memória e de auto-aprimoramento).
- **Memória**: [`memoria/`](memoria) — perfil, preferências, pessoas e aprendizados. O repositório é a memória do agente.
- **Tarefas**: [`tarefas/TAREFAS.md`](tarefas/TAREFAS.md) — quadro único.
- **Painel**: [`painel/PAINEL.md`](painel/PAINEL.md) — o estado atual em uma tela.
- **Rotinas**: [`rotinas/`](rotinas) — briefing matinal, revisão noturna, varredura de agentes, revisão semanal com auto-aprimoramento. Rodam sozinhas por agendamento e mandam notificação no celular.
- **Agentes**: [`agentes/registro.md`](agentes/registro.md) — Promoções, Papelada Médica, TCC.
- **Canais**: [`comunicacao/canais.md`](comunicacao/canais.md) — nunca e-mail; Claude app agora, Telegram/WhatsApp como próxima fase.

## Falar com o Concierge
Abra uma sessão do Claude Code neste repositório e converse. Tudo que for relevante vira memória ou tarefa.
